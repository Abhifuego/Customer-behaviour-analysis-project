# Customer Behavior Analysis

This project focuses on analyzing customer shopping behavior using Python, SQL, MySQL, and Power BI. The objective of the project is to extract meaningful business insights from customer purchasing data through data cleaning, analysis, visualization, and interactive dashboarding.

---

# Project Overview

The project involves end-to-end data analytics workflow including data preprocessing, exploratory data analysis, SQL-based business problem solving, KPI generation, and Power BI dashboard development. The analysis helps businesses understand customer purchasing patterns, revenue trends, subscription behavior, and sales performance.

---

# Business Problem

Businesses often struggle to understand customer purchasing behavior, spending patterns, and product performance. This project aims to solve these challenges by analyzing customer transaction data to uncover insights that can support better business decisions and improve customer engagement strategies.

---

# Objectives

- Perform data cleaning and preprocessing on customer shopping data
- Analyze customer purchasing behavior and trends
- Generate business insights using SQL queries
- Create KPIs for business performance tracking
- Build an interactive Power BI dashboard
- Apply data storytelling techniques for business understanding
